## Modalità di ricostruzione

### Ripristino esatto dello stato dati pre-STEP 0

Il dump privato è la fonte da usare quando servono struttura e dati esatti. Prima di qualsiasi ripristino verificare il checksum:

```bash
shasum -a 256 php/storage/app/private/backups/changeaccount-step0-20261109-220602.sql
```

Il risultato deve coincidere con il valore riportato sopra. Importare sempre prima in un database isolato e mai direttamente nel database operativo senza fermare le scritture e creare un ulteriore backup.

Esempio con un database di destinazione già creato e deliberatamente scelto:

```bash
/Applications/MAMP/Library/bin/mysql80/bin/mysql \
  --host=127.0.0.1 \
  --port=3306 \
  --user=root \
  --password \
  NOME_DATABASE_ISOLATO \
  < php/storage/app/private/backups/changeaccount-step0-20261109-220602.sql
```

### Ricostruzione della sola struttura cumulativa

La migration esatta può essere estratta dal tag senza dipendere dalla versione corrente del file:

```bash
git show db-pre-step0-20261109:php/migration/migration.txt \
  > /tmp/coccolebestiali-migration-pre-step0.sql
```

Prima dell'esecuzione sostituire `{{DB_DATABASE}}` con il nome del database isolato e seguire la procedura descritta in `php/migration/README.md`. I seed possono essere estratti nello stesso modo cambiando il percorso dopo i due punti.
